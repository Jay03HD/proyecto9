# DSS de ventas Walmart

Dashboard web de apoyo a la decisión (DSS) sobre las ventas semanales de 45 tiendas Walmart (feb 2010 – oct 2012).

**Sitio publicado:** https://USUARIO.github.io/dss-ventas-walmart/  <!-- reemplaza USUARIO -->
